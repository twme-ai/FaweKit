# Changelog

All notable changes to FaweKit are documented in this file.

## 0.1.0 - 2026-08-11

- Initial public release.
- Added selection teleporting, stacks, persistence, and fuzzy schematic search.
- Added clipboard resizing, automatic rotation, nearby-mask copy, and multi-replace.
- Added shortcuts, pinned command locations, biome masks, environmental masks,
  parser help, block globs, and compatibility aliases.
- Added JUnit coverage, a Mineflayer protocol test, and GitHub Actions builds.
